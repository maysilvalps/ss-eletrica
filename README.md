# SS Ar Condicionado e Eletrica

Projeto de plataforma web institucional e de servicos voltada para o setor de climatizacao e infraestrutura eletrica, desenvolvido para operacao em Rondonopolis - MT.

## Visao Geral

O sistema apresenta uma identidade visual moderna com modo escuro tecnico, trilhas de circuitos animadas, ferramentas interativas para o cliente (como simulador de impacto energetico e abertura de chamados via WhatsApp), alem de um portfolio dinamico de servicos.

## Tecnologias Utilizadas

* **HTML5**: Estruturação semântica das páginas.
* **CSS3**: Estilização avançada, variaveis globais, layout responsivo e animacoes por keyframes.
* **JavaScript (ES6+)**: Logica de interatividade, controle do menu mobile, simulador de consumo energetico e renderizacao dinamica de componentes.

## Funcionalidades

* Cabecalho fixo com efeito de transparencia na rolagem da pagina.
* Menu responsivo (hamburguer) otimizado para dispositivos Moveis.
* Animacao de circuitos eletricos no Hero e secoes de sustentabilidade.
* Simulador de consumo energetico para calculo de kWh e custo estimado.
* Formulario integrado para envio direto de chamados tecnicos via WhatsApp.
* Secao de portfólio e relatorios tecnicos de campo.

## Estrutura de Arquivos

* `index.html`: Pagina principal da aplicacao.
* `portfolio.html`: Pagina dedicada ao portfolio de servicos e relatorios tecnicos.
* `estilo.css`: Folha de estilos global e responsiva.
* `script.js`: Logica em JavaScript para interatividade e calculos.
* `img/`: Diretorio de ativos visuais e logotipos.

## Como Executar

1. Clone o repositorio em sua maquina local.
2. Abra a pasta do projeto em um editor de codigo (como o VS Code).
3. Abra o arquivo `index.html` diretamente em seu navegador web preferido ou utilize uma extensao de servidor local (como o Live Server).
